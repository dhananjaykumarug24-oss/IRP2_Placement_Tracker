# Placement Readiness Tracker

## Project Description
The Placement Readiness Tracker is a Python-based project that manages student placement preparation scores and identifies students who need more practice.

## Features
- Stores student details and scores.
- Accepts new student data.
- Validates scores between 0 and 100.
- Calculates average scores and grades.
- Finds the top scorer.
- Identifies students who need practice.
- Finds the second-highest distinct score.

## Technologies Used
- Python
- Git
- GitHub

## Project Files
- `main.py` – Student data management and placement tracker.
- `runnerup.py` – Runner-up score problem solution.

## How to Run

```bash
python3 main.py
```

To run the runner-up program:

```bash
python3 runnerup.py
```
